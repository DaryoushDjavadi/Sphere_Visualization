# Wendi Crush

Match-3 Prototype im Browser — Geschenk-Spiel für Wendi.

## Lokal starten

Einfach den Ordner öffnen:

```bash
cd wendi-crush
# Option A: direkt index.html im Browser öffnen
open index.html

# Option B: kleiner Local Server
python3 -m http.server 5173
# dann http://localhost:5173
```

## Prototyp-Inhalt

- Title Screen **Wendi Crush** (Flieder + Orange)
- 8×8 Board, 5 Sticker-Steine: Katze, Tiger, Affe, Schwamm, Herz
- Tippen zum Tauschen benachbarter Steine
- Matches ab 3, Cascades, Score + Züge
- Ziel: **800 Punkte** in **20 Zügen**
